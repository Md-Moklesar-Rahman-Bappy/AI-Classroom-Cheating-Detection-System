# Privacy Review

- No identifiable participant names in dataset manifest (`P_SYN_01` only).
- Real participant recordings blocked until full consent verified.
- Consent template (`CONSENT_TEMPLATE.md`) covers purpose, storage, retention, viewers, withdrawal rights.
- Data retention policy (`DATA_RETENTION_POLICY.md`) defines 90-day default, secure deletion.
- Evidence directory excluded from Git; raw videos not in repository.
- Evidence snapshots: track number + event label only; no names/student IDs.
- No biometric templates; temporary track IDs only.
- Human review required before any automated alert action (`docs/VIDEO_ASSET_ACTIONS.md`).
