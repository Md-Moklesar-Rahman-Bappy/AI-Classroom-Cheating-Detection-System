# Quality Control

- Two-pass annotation: annotator + reviewer.
- Inter-annotator agreement: 10% double-annotated; Cohen's kappa reported.
- Positive, negative, uncertain, start/end, occlusion, overlapping event policies documented.
- Small-object policy (< 16x16 px): marked `uncertain`.
- Reviewer identifier: non-sensitive code (e.g., `R01`).
